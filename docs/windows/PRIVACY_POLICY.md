# Privacy Policy — Quant Scenario Studio by LAI ZEYU

Effective date: 27 August 2026

Quant Scenario Studio is authored by **LAI ZEYU（来泽宇）**. It is a
local Windows research and education application. The source repository and
internal research engine may use the name Aegis Forecast.

## Summary

The Microsoft Store edition has no advertising, analytics telemetry, cloud
account, remote application server, brokerage SDK or financial-account
connector. It uses deterministic synthetic data bundled with the app and can run
offline. It does not display live or latest market data.

## Data stored locally

The app may store the research-notice acknowledgement, illustrative-file
integrity records, lifecycle state and hash-chained audit evidence in its
marker-bound Windows package LocalState directory. These files remain on the
device and are not sent to LAI ZEYU（来泽宇）.

The Privacy page can reset the acknowledgement and delete app-owned LocalState.
Deletion first requires the exact PFN/path ownership marker, then addresses only
documented application directories and database files; unknown siblings remain.

Windows or Microsoft Store may retain installation, crash or Store records under
Microsoft's own services and policies. Those records are not collected by this
application.

## Financial data and decisions

The Store package does not read or store brokerage accounts, balances,
positions, orders, transaction history, credentials or trade-unlock values. It
does not place, cancel or schedule orders in any environment, give personalized
investment advice or guarantee performance.

The Nasdaq-100 constituent identifiers are from the official snapshot dated
26 August 2026. All displayed reference values, scores and outcomes are stable-
hash deterministic synthetic examples, not market observations or trained results.

## Local security

The WinUI shell and research sidecar communicate over a loopback-only HTTP
session using fresh random session/CSRF tokens, an HttpOnly cookie and
same-origin checks. WebView2 blocks non-loopback navigation. This local socket is
not a remote data service and must not be exposed to the internet.

## Sharing, sale and retention

LAI ZEYU（来泽宇） does not receive, sell or share data from this app.
There is no tracking SDK or remote analytics endpoint. Local research state
remains until the user deletes it in the app, resets/uninstalls the app, or
removes it through Windows.

## Children

The app is a general research/education tool and is not directed at children. It
does not knowingly collect personal information from children.

## Changes and contact

Material policy changes will be published with a new effective date. Privacy or
security questions can use the repository's
[private reporting channel](https://github.com/lzy2767865503-pixel/aegis-forecast/security/advisories/new).
Do not include credentials, personal records or financial data in a public issue.
