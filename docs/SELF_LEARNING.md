# 受控自学习模型

“自学习”不是让系统在交易时自己改代码、降阈值或直接上实盘。Aegis A 把它定义为“可重现的经验积累 + 受管制的模型竞争”。

## 闭环

1. 盘中只保存特征快照、信号、风控判断、委托和成交事实。
2. 标签只在持有期完成后成熟，买入和卖出使用不同标签。
3. 收盘后生成训练快照，用 Purged Walk-Forward 和 Embargo 避免样本泄漏。
4. 当前 Champion 保持冻结，Challenger 只能在相同数据、费用、风险预算和交易约束下比较。
5. 每次训练记录数据截止时间、特征版本、参数、指标、产物哈希和审计 Trace ID。
6. Challenger 先进入至少60个交易日影子运行，不发单。
7. 只有在精度、收益/风险、尾部损失、换手、容量、稳定性和漂移都通过后，才可由人工批准替换。

## 当前硬门槛

- 分钟级成熟样本至少 2,000 个。
- 高置信号样本至少 200 个。
- 影子运行至少 60 个交易日。
- 必须有人工批准；永久禁止自动实盘晋级。
- 任何异常、数据漂移或审计不一致都会阻断晋级。

## 评估指标

除年化收益、Sharpe、最大回撤和胜率外，必须同时看概率校准、净费后收益、不同市场状态稳定性、单股/行业集中度、冲击成本、委托拒绝率与模型漂移。单一“胜率”不允许成为上线理由。
