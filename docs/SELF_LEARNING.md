# 本地说明性文件核对

Store 版没有 self-learning、训练、挑战模型、晋级或自动替换功能。“本地完整性
记录”页面只核对随包确定性合成情景文件，并将核对哈希写入本机审计链。

## 核对内容

1. `illustrative_scenario_outcomes.csv` 必须正好包含 300 行。
2. 每行生成方法必须是 `stable-sha256-v1`。
3. API 必须从全部随包行实时重算说明性指标。
4. 重算结果必须与 `scenario_metrics.json` 完全一致。
5. 本机记录只保存文件哈希、行数、核对状态与时间。
6. 应用永久不训练、不比较、不替换模型，也没有任何交易能力。

这些核对只能证明文件完整性和计算可复现性，不能被表述为准确率、历史表现、
收益证据或投资建议。
