# Synthetic demo artifacts

Files in this directory are generated by `scripts/generate_demo_data.py` from
public security codes and stable salted SHA-256 fractions. They are deterministic
synthetic fixtures used so a fresh clone renders a complete dashboard offline.

They are not live or historical market observations, trained-model output,
backtests, investment signals, customer records, broker exports or performance
claims. `scenario_metrics.json` is derived from every row in
`illustrative_scenario_outcomes.csv` and is checked again at runtime and in tests.
